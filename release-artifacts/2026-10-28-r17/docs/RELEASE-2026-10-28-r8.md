# Destiny RTM prerelease — 2026-10-28 revision 8

This revision improves the spawn catalog's type hint. A selected catalog type
now shows its possible BLES object-name table label (for example, type 9 shows
`biped`). The guard remains opt-in. Static evidence supports this candidate:
the hash-matched BLES 01.24 EBOOT has an ordered 25-record type-name table, and
its object constructor copies definition byte `+0x4E` to sObject `+0x08`, the
byte Blackrock's guard compares. The direct catalog-to-guard mapping and live
spawn behavior are still unverified.

No inventory write action was added. A live BLES 01.24 item-list pointer and
safe write routine remain unresolved. The development PS3's webMAN endpoint on
TCP port 80 was unreachable, so no live reads or writes were attempted.
