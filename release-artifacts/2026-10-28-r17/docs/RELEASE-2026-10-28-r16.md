# Destiny RTM prerelease — 2026-10-28 revision 16

R16 extends the read-only spawn-tag probe. The BLES 01.24 constructor reads
definition byte `+0x4E` and copies it to created-object byte `+0x08`; Blackrock
operation 1 compares that byte with its optional expected-type guard. The probe
now verifies the exact constructor instruction signature, samples the resolved
definition byte twice, and reports whether it matches the selected guard. A
changing byte or mismatched signature is refused before the result is shown.
This is useful for checking the guard for a candidate tag; it does not prove the
tag is loaded, hostile, successfully created, or correctly placed.

R15's live item-pool comparison remains available. Inventory mutation is still
unimplemented because the Blackrock confirmation callback has not been linked
to a verified BLES item-action handler or transport.

The development PS3 at `192.168.0.62` did not accept TCP connections on
webMAN port 80 or PS3MAPI port 7887 during this pass. The spawn probe was not
run on hardware. The source audit still finds no RTM path that stops or starts
PS3MAPI; health checks query the read-only `SERVER GETVERSION` endpoint.
