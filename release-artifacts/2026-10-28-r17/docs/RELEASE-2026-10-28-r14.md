# Destiny RTM prerelease — 2026-10-28 revision 14

R14 adds an explicit BLES 01.24 build-profile check before the Overwalls
consumable randomizer reads its source-derived 20-row table and before its
restorer reads the saved target bytes. A mismatch leaves the console memory
untouched and preserves any restoration journal. The table at `0x600EAE60`
and its row meaning are still Overwalls-derived; they have not been
independently verified on a live BLES console. See the caution beside the
control and [the Overwalls port map](OVERWALLS-PORT.md).

Inventory research now documents the resolved Blackrock UI route into a
delayed confirmation callback, the generic PS3MAPI writer, and the missing
link between them. The BLES 01.24 402–405 switch groups parse indexed byte
records but are not mapped to inventory operations. D1 Reimagined's matching
message IDs belong to PS4 01.33 and remain a cross-platform hypothesis, not
PS3 address or action evidence. No inventory writer was added.

The r13 offline character-snapshot comparison remains available. The spawn
executor is experimental; the development console at `192.168.0.62` did not
accept TCP connections on PS3MAPI port 7887 or webMAN port 80 during this
build pass, so no live-console validation was possible.
