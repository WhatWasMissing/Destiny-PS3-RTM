DESTINY RTM — PRERELEASE R17

R17 adds a visible Windows startup error dialog when the default local port is already occupied. The dialog explains how to close the other host or use a second loopback port. The existing host at 127.0.0.1:8767 was left running; no PS3 requests were sent.

The experimental spawn feature and read-only BLES constructor type-byte probe from R16 are unchanged. Live spawning and inventory mutation remain unverified or unavailable. Read docs\RELEASE-2026-10-28-r17.md and SPAWNING-INSTRUCTIONS.txt.
