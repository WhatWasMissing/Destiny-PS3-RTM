# Destiny RTM prerelease — 2026-10-28 revision 9

This rebuild removes the duplicate legacy palette from `base.css`, leaving
`design.css` as the single source for dark and light color tokens. Light-mode
placeholders and connected/active status surfaces now use those shared tokens.
The spawn catalog labels and opt-in guard from r8 are unchanged.

The Blackrock inventory audit also found its six host-side action IDs, but no
verified BLES 01.24 mutation target or request format. Inventory editing stays
unimplemented; the static boundary is documented in
`research/inventory-action-evidence.md`. The PS3 endpoint was unreachable, so
this build was not validated against live hardware.
