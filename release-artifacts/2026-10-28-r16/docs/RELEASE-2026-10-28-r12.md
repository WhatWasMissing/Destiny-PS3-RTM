# Destiny RTM prerelease — 2026-10-28 revision 12

R12 continues the shared design-token cleanup: the setup dialog's primary
button now uses the theme-aware accent ink, and the safety acknowledgement
uses the shared success surface and border colors. These fixes remove two
remaining hard-coded colors that clashed with the graphite/muted-accent
palette.

The local BLES 01.24 item catalog was also passed through the production
catalog importer. All 6,389 named entries loaded without truncation and mapped
to in-range item indexes. The game-derived catalog remains local and is not
included in this release. This supports the existing read-only item-name
snapshots; it does not add inventory mutation. See
[`research/item-catalog-load-audit.md`](../research/item-catalog-load-audit.md).

This build includes r11's numeric memory-address correction, 32-bit range
check, and 332-byte shared-hook ownership check. The shared-hook and spawn
integration checks use a fake console. The development PS3 at `192.168.0.62`
returned `DestinationHostUnreachable` and did not accept TCP connections on
ports 80 or 7887, so no live-console validation was possible. Spawn success
and inventory mutation remain unverified on hardware.

## Verification

- Go 1.27.3 tests passed.

- Packaged desktop smoke checks passed; they sent no console requests.
- CLI help and MCP initialize/tool-list smoke checks passed.
