DESTINY RTM — PRERELEASE R16

Start DestinyRTM.exe. R16 adds a read-only BLES constructor type-byte sample to the Spawn Tag probe. It compares the resolved definition's +0x4E byte against the optional expected-type guard. This can flag a mismatch before submitting a request, but it does not prove that a tag is a hostile enemy or will spawn.

Live inventory mutation remains unimplemented. The spawn executor remains experimental and has not been validated on a PS3 in this build pass. Read docs\RELEASE-2026-10-28-r16.md and SPAWNING-INSTRUCTIONS.txt.
