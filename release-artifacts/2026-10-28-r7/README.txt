DESTINY RTM — PRERELEASE R7

Start DestinyRTM.exe. This is a rebuilt Windows desktop app with companion
rtmctl.exe and rtm-mcp.exe tools. Read RELEASE-2026-10-28-r7.md for build
verification and hashes. Read PRERELEASE-TOOLS.txt for direct read-only
console commands and SPAWNING-INSTRUCTIONS.txt before using the experimental
spawn panel.

The live and offline inventory views can show name, bucket and type from an
explicitly BLES-indexed item catalog. Spawn catalog types remain unverified
candidates and are not applied automatically.
