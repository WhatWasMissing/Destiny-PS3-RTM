# Destiny RTM prerelease — 2026-10-28 revision 13

R13 adds an offline before/after comparison for two BLES 01.24 character QZ
inventory payloads. It reports added, removed, and changed inventory slots by
item index and can use the locally imported BLES-indexed item catalog for
labels. The comparator validates the exact QZ size and header, clears its file
inputs after reading, and never displays or retains instance/owner IDs. It is
a snapshot diagnostic; it does not transfer, equip, dismantle, or use items.
See [`research/inventory-snapshot-comparison.md`](../research/inventory-snapshot-comparison.md).

The BLES 01.24 live item-pool reader remains read-only and still does not map
items to a character or vault. The Blackrock trace distinguishes its native
route-validation record and generic PS3MAPI write primitive, but does not
establish a call from its inventory action callback to that primitive. The
BLES mutation boundary remains unknown; no inventory write was added. The
operation-1 spawn controller remains experimental and has not been validated
on a live console. At this build, PS3MAPI port 7887 and webMAN port 80 at
`192.168.0.62` did not accept TCP connections, so live-console validation was
not possible.
