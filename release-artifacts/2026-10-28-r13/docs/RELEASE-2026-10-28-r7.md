# Destiny RTM prerelease — 2026-10-28 revision 7

This revision adds the imported BLES 01.24 item catalog's `bucket` and `type`
fields to the live item-pool and offline inventory views, alongside item index
and name. Catalog rows still require an explicit `itemIndex` or
`blesItemIndex`; out-of-range indexes are ignored, and the catalog's `tag`
column is never joined to memory. The game-derived catalog remains user-imported
and is not bundled.

This build also includes r6's spawn-catalog update: numeric catalog types are
preserved as unverified metadata and can be copied to the optional expected-type
guard only through a separate explicit action. Live spawn behavior and the
catalog-to-guard mapping remain unverified.
