# Destiny RTM prerelease — 2026-10-28 revision 4

This revision extends the read-only BLES 01.24 actor-candidate snapshot with
the raw packed handle stored at actor record `+0x226C`. The build now verifies
the exact caller and resolver signatures, samples and rechecks the handle, and
reports its decoded bucket/slot arithmetic. Static analysis confirms that the
resolver uses a second manager root at `0x01896D50`; the target object and its
class are still unknown, so the tool does not follow the handle or label an
actor as an enemy. The source comparison also now distinguishes the confirmed
BLES object-creation entry from unresolved Blackrock argument and tag semantics.

## Verification

- Go package tests passed.
- All 104 JavaScript tests passed.
- Desktop, CLI, and MCP protocol smoke checks passed.
- No PS3 request was sent during the build. A separate read-only actor-pool
  profile check afterward timed out awaiting the PS3MAPI HTTP headers, so live
  actor layout, enemy correlation, inventory-label catalog coverage, and
  spawning remain unverified on the development console.
