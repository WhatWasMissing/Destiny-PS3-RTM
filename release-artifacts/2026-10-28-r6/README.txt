DESTINY RTM — PRERELEASE R6

Start DestinyRTM.exe. This is a rebuilt Windows desktop app with companion
rtmctl.exe and rtm-mcp.exe tools. Read RELEASE-2026-10-28-r6.md for build
verification and hashes. Read PRERELEASE-TOOLS.txt for direct read-only
console commands and SPAWNING-INSTRUCTIONS.txt before using the experimental
spawn panel.

This revision preserves numeric spawn catalog types and offers an explicit,
unverified action to copy one into the expected-type guard. Live spawning and
the catalog-to-guard mapping remain unverified on the PS3.
