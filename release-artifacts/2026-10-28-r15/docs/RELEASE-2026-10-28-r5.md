# Destiny RTM prerelease — 2026-10-28 revision 5

This revision tightens the live BLES 01.24 inventory name lookup to the
package-verified item range, indexes `0`–`6556`. The generic catalog table can
still display larger user-provided keys; those rows no longer label live
inventory objects. A new regression test covers both ends of the range and
rejects larger values.

The welcome screen now uses the same flat panel, system typography, palette,
and hex emblem as the rest of the app. Its decorative full-screen JPEG and the
1.05 MB script that loaded it were removed.

## Verification

- `go test ./...` passed using Go 1.27.3.
- All 106 JavaScript tests passed.
- JavaScript syntax checks passed.
- Packaged desktop smoke checks passed.
- CLI help and MCP initialize/tool-list smoke checks passed.
- Build smoke checks sent no console requests. A later read-only actor-pool
