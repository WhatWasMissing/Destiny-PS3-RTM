# Destiny RTM prerelease — 2026-10-28 revision 17

R17 fixes an unclear startup failure when the default local port is already in
use. A double-click launch now shows a Windows error dialog with the occupied
address and a command to run on an alternate loopback port. Console launches
with `-no-open` keep the error in terminal output. The app does not silently
choose another port, which would switch browser storage origins.

The reported failure was reproduced: the r16 binary exited with Windows
`WSAEADDRINUSE` because the older `dist/DestinyRTM.exe` process already owned
`127.0.0.1:8767`. It was not an application crash. The existing process was
left running; no PS3 requests were sent.
