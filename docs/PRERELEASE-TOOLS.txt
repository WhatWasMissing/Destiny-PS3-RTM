DESTINY RTM — DIRECT TOOLS

Run these commands in PowerShell from this prerelease folder. Replace the
example address with the PS3's current private IPv4 address. The desktop app
does not need to be running.

Check webMAN reachability:
  .\rtmctl.exe status --ip 192.168.0.62 --json

Inspect the BLES 01.24 actor-pool descriptor:
  .\rtmctl.exe actor-pool --ip 192.168.0.62 --json

The actor-pool command verifies the five-anchor build profile and full actor
code signature, reads/rechecks the 20-byte descriptor, and validates capacity
40 and stride 0x28D0 when initialized. It reads zero actor records and does not
identify loaded enemies or confirm spawning.

Read the bounded BLES 01.24 item-object pool:
  .\rtmctl.exe inventory-pool --ip 192.168.0.62 --json

List all CLI commands:
  .\rtmctl.exe help

rtm-mcp.exe is a stdio MCP server for agent clients. Its named read-only tools
include rtm_verify_build, rtm_read_actor_pool_descriptor and
rtm_read_live_inventory_pool. It is not a graphical app; an MCP client launches
it and sends JSON-RPC requests. Setup is documented in the source repository's
docs/RTM-MCP.md. All commands communicate directly with the specified PS3.
