# Destiny RTM prerelease — 2026-10-28 revision 2

This build corrects the inventory address audit after identifying that a local
ELF named `PATCH0024` was actually the BLES 01.00 base-game executable. The
verified BLES 01.24 inventory pool reader remains read-only and returns raw
item indexes. Catalog imports now accept the nonnegative signed-16-bit index
range without claiming that the available base-disc package list is the exact
01.24 name table.
