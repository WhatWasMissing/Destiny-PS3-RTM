# Destiny RTM prerelease — 2026-10-28 revision 6

This revision carries numeric `type` values from imported spawn catalogs into
the candidate list and adds a separate action to copy one into the optional
Blackrock expected-type guard. Selecting a catalog row still copies only its
tag, and the guard continues to default to `-1` (disabled).

Static evidence now establishes that BLES 01.24 object creation copies a
definition byte into created sObject `+0x08`, which Blackrock's executor
compares with packet `+0x24`. The ordered BLES object-type names and Blackrock
catalog examples strongly suggest a shared object-kind enum. The direct mapping
from catalog type to the guard is still unverified, so the new UI action warns
that applying a wrong type may reject the spawn. Type 9 is a broad object kind
and also appears on player Guardians; it does not mean “enemy.” See
[`spawn-type-evidence.md`](../research/spawn-type-evidence.md) and
[`BLACKROCK-FEATURE-PORT.md`](BLACKROCK-FEATURE-PORT.md).
