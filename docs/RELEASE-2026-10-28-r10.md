# Destiny RTM prerelease — 2026-10-28 revision 10

This rebuild gives the macro dialog the same restrained overlay and shared
dialog shadow used elsewhere, in both light and dark themes. The dialog shadow
is now a theme token. No gameplay or memory-write behavior changed.

The BLES 01.24 inventory investigation found switch-like code comparing IDs
402–404, but its inspected blocks look like generic field decoding or
serialization. The scan did not prove those are Blackrock inventory actions.
Rizin string-xref results were inconclusive because of ELF parsing warnings.
Inventory writes remain unimplemented; see
[`research/inventory-action-evidence.md`](../research/inventory-action-evidence.md).
An audit of a local older 1.08 RTM also found no spawn or inventory feature
and no verified BLES 01.24 offsets; see
[`research/detertrots-108-source-audit.md`](../research/detertrots-108-source-audit.md).
